Pydantic SchemaForms

Describe a form once, as a Pydantic model. The library draws it as a styled HTML form, checks what people type, shows each mistake next to its field, and hands your code clean data.

It runs on your server with FastAPI or Flask, so there is no JavaScript framework to learn. Bootstrap, Material Design or plain HTML; light or dark.

How it works

A form is a Python class. Each field is one input: its type picks the kind of input, and its rules (such as "at least 2 characters") are checked when the form comes back.

Grows with the form

  • Long forms become tabs, an accordion or a step wizard by changing one word, and can save each step so people can come back later.
  • Forms inside forms, such as an address, and lists people can add to, such as pets or line items, come back as nested data.
  • Fields that appear when needed, live checks as you type, file uploads checked on the server, and CSV import into an editable table.
  • Safe by default: text people type can never turn into code on your page, and it works under a strict Content-Security-Policy.
  • Accessible: every input is tested for screen readers and keyboard use.
