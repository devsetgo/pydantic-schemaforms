Every page on this site runs under a strict Content-Security-Policy. This page shows the policy and lets you watch it block a script. Async

In plain English

If an attacker ever slipped a script into a web page, the browser would run it along with the site's own scripts. A Content-Security-Policy is a rule the server sends with each page saying which scripts and styles may run. This site allows only those carrying a nonce: a random value made fresh for each page, like a wristband for one event. An injected script doesn't have this page's wristband, so the browser refuses to run it.

The form below brings its own scripts and styles (the color swatch, the date picker, the bold note). They all carry the nonce, so they work. The app passed the nonce to the library once, in its middleware, not to this form.
